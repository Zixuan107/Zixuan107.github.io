# Portfolio Template

Files:
- index.html
- research.html
- projects.html
- personal.html
- style.css
- assets/

Before publishing:
1. Replace YOURUSERNAME in index.html with your GitHub username.
2. Replace YOUR_EMAIL with your email.
3. Add your LinkedIn URL.
4. Put your headshot in assets/headshot.jpg.
5. Put your resume in assets/Peter_Fu_Resume.pdf.
6. Add/replace project images in the assets folder.
7. Replace placeholder '#' links with your real GitHub, paper, demo, or website links.

To test locally:
- Double-click index.html and open it in Chrome/Safari.
